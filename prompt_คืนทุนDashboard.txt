ขอเพิ่มวิดเจ็ต "ติดตามการคืนทุน" ในหน้าแดชบอร์ด เพื่อให้ admin เห็นว่าลงทุนปรับปรุงไปเท่าไหร่ กำไรสะสมถึงไหนแล้ว และจะคืนทุนเมื่อไหร่ โดยมีตาราง resort_settings ในฐานข้อมูลพร้อมแล้ว (สร้างไว้แล้ว มี 1 แถว มีฟิลด์ investment_cost และ investment_start_date)

ให้ทำตามนี้:

**1. วิดเจ็ตในหน้าแดชบอร์ด (เห็นเฉพาะ admin)**

แสดงการ์ด/กล่อง "ติดตามการคืนทุน" มีข้อมูลดังนี้:
- ต้นทุนลงทุนทั้งหมด: X บาท (จาก investment_cost ใน resort_settings)
- กำไรสุทธิสะสม: Y บาท (sum ของ transactions ตั้งแต่ investment_start_date ถึงวันนี้ โดย income - expense)
- คืนทุนแล้ว / ยังขาดอีก: แสดงเป็นบวก/ลบ (ถ้า Y >= X แสดงว่าคืนทุนแล้ว ถ้า Y < X แสดงว่ายังขาดอีก X-Y บาท)
- Progress bar แสดงเปอร์เซ็นต์คืนทุน (Y/X * 100%) สีเขียวถ้าคืนทุนแล้ว สีน้ำเงินถ้ายังไม่คืน
- ประมาณการคืนทุนอีกกี่เดือน: คำนวณจากค่าเฉลี่ยกำไรสุทธิต่อเดือน (ใช้ข้อมูลย้อนหลัง 3 เดือนล่าสุด) หารกับยอดที่ยังขาด → แสดงเป็น "อีกประมาณ N เดือน" (ถ้าคืนทุนแล้วแสดง "คืนทุนแล้ว!")
- ปุ่ม "แก้ไขข้อมูลทุน" เล็กๆ ที่มุมการ์ด สำหรับเปิด modal แก้ไข (ข้อ 2)

**2. Modal "แก้ไขข้อมูลทุน" (admin only)**

เปิดได้จากปุ่มในวิดเจ็ต มีฟิลด์:
- ต้นทุนปรับปรุงรวม (บาท): input number
- วันที่เริ่มนับกำไรสะสม: date picker (เพื่อให้กรอกได้ทีหลัง เช่น วันเปิดรีสอร์ทจริง)
- ปุ่มบันทึก → update ตาราง resort_settings แถว id=1 แล้วรีเฟรชวิดเจ็ต

**3. Server Action**
สร้าง server action สำหรับ:
- getResortSettings() → select จาก resort_settings
- updateResortSettings({ investment_cost, investment_start_date }) → update แถว id=1
