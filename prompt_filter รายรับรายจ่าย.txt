ขอเพิ่ม filter แบบ checkbox ในหน้า รายรับ-รายจ่าย (app/(protected)/transactions/TransactionsClient.js หรือไฟล์ที่เกี่ยวข้อง)

**filter ที่ต้องการ (วางใต้ช่วงวันที่เดิม):**

───────────────────────────
1. filter ประเภท
───────────────────────────

แสดงเป็น checkbox 2 ตัวเลือก:
☑ รายรับ   ☑ รายจ่าย

- default: ติ๊กทั้งสอง (แสดงทุกรายการ)
- ถ้าติ๊กแค่อันเดียว → filter เฉพาะประเภทนั้น
- ถ้าไม่ได้ติ๊กเลย → ไม่แสดงรายการใดเลย

state ตัวอย่าง:
```js
const [typeFilter, setTypeFilter] = useState({ income: true, expense: true })
```

───────────────────────────
2. filter หมวดหมู่
───────────────────────────

- ดึงหมวดหมู่จากตาราง transaction_categories (มีอยู่แล้วในระบบ)
- แบ่งเป็น 2 กลุ่ม: หมวดรายรับ และ หมวดรายจ่าย
- แสดงเป็น checkbox ทั้งหมด default ติ๊กทุกอัน
- มีปุ่ม "เลือกทั้งหมด / ยกเลิกทั้งหมด" สำหรับแต่ละกลุ่ม

ตัวอย่าง UI:

```
หมวดรายรับ          [เลือกทั้งหมด] [ยกเลิก]
☑ ค่าห้อง
☑ ค่าบริการ
☑ ขายของ

หมวดรายจ่าย         [เลือกทั้งหมด] [ยกเลิก]
☑ ค่าน้ำ-ค่าไฟ
☑ ซื้อของ
☑ ค่าซ่อมบำรุง
```

state ตัวอย่าง:
```js
const [categoryFilter, setCategoryFilter] = useState(
  new Set(allCategories.map(c => c.id))  // default: ทุก category ติ๊กหมด
)
```

───────────────────────────
3. Logic การกรอง
───────────────────────────

filter ทุกตัวทำงานร่วมกัน (AND) กับ date range เดิม:

```js
const filtered = transactions.filter(tx => {
  // date range (เดิม)
  const inDateRange = tx.tx_date >= startDate && tx.tx_date <= endDate

  // ประเภท
  const inType = (tx.tx_type === 'income' && typeFilter.income) ||
                 (tx.tx_type === 'expense' && typeFilter.expense)

  // หมวดหมู่
  const inCategory = categoryFilter.has(tx.category_id)
  // ถ้า transaction ไม่มี category_id ให้แสดงเสมอ (กัน null)

  return inDateRange && inType && inCategory
})
```

───────────────────────────
4. ยอดรวม
───────────────────────────

รายรับรวม / รายจ่ายรวม / กำไรสุทธิ ให้คำนวณจากรายการที่ผ่าน filter แล้วเท่านั้น
(ไม่ใช่ยอดรวมทั้งหมด)

───────────────────────────
5. UI Layout
───────────────────────────

วาง filter panel ใต้ date range เดิม ก่อนตาราง:

```
[กรองช่วงวันที่] ─────────────────────
[ประเภท]  ☑ รายรับ   ☑ รายจ่าย
[หมวดรายรับ]  ☑ค่าห้อง ☑ค่าบริการ ...  [เลือกทั้งหมด][ยกเลิก]
[หมวดรายจ่าย] ☑ค่าน้ำ ☑ซื้อของ ...     [เลือกทั้งหมด][ยกเลิก]
──────────────────────────────────────
ยอดรวม (จาก filter)
──────────────────────────────────────
ตารางรายการ
```

ใช้ Tailwind สไตล์เดิมของระบบ (ไม่ต้องใช้ library ใหม่)
filter panel อาจ collapsible ได้ถ้าเห็นว่ากินพื้นที่มาก
