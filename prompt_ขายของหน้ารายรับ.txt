ที่หน้า /transactions (รายรับ-รายจ่าย) ตอนนี้มีปุ่ม "เพิ่มรายการ" กับ "ปิดยอดประจำวัน" อยู่แล้ว ช่วยเพิ่มปุ่มใหม่ "บันทึกขายของ" ไว้ข้างๆ ปุ่มเดิม เพื่อให้พนักงานบันทึกการขายสินค้าได้จากหน้านี้เลย โดยไม่ต้องสลับไปหน้า /inventory ตามนี้:

1. ปุ่ม "บันทึกขายของ" กดแล้วเปิดฟอร์มเล็ก มีช่อง:
   - เลือกสินค้า (dropdown) — ดึงรายการจาก inventory_items ที่ is_for_sale = true เท่านั้น แสดงชื่อสินค้า + สต๊อกคงเหลือ + ราคาขาย/หน่วย ให้เห็นในตัวเลือก
   - จำนวนที่ขาย (ตัวเลข)
   - แสดงยอดเงินรวมที่คำนวณอัตโนมัติ (ราคาขาย x จำนวน) ให้เห็นก่อนกดบันทึก

2. กด "บันทึก" แล้วทำ 2 อย่างพร้อมกัน (ถ้าอันใดพลาด ให้ทั้งคู่ไม่เกิด) — ใช้ฟังก์ชัน/logic เดียวกับปุ่ม "ขาย" ที่มีอยู่แล้วในแท็บ "ขายของ" หน้า /inventory ไม่ต้องเขียนแยกซ้ำ เรียกใช้ของเดิมร่วมกัน:
   - เพิ่มรายรับใน transactions: tx_type='income', category='ขายของ', amount = ราคาขาย x จำนวน, note = "ขาย <ชื่อสินค้า> x<จำนวน>"
   - บันทึก inventory_movements: movement_type='sale', quantity=จำนวน, transaction_id = id ของรายรับที่สร้างขึ้น
   - ถ้าจำนวนที่ขาย มากกว่าสต๊อกที่มี ให้เตือนและไม่บันทึก

3. หลังบันทึกสำเร็จ ให้รายการขายนี้ปรากฏในตารางรายการของหน้า /transactions ทันที (เหมือนรายรับอื่นๆ) และอัปเดตสต๊อกที่หน้า /inventory ด้วย (เพราะใช้ฐานข้อมูลเดียวกัน)

4. ตรวจสอบว่าหน้า /dashboard ที่สรุปยอดรายรับสะสม/รายรับรายเดือน/กราฟยอดขาย ดึงข้อมูลจาก transactions ทั้งหมดอยู่แล้ว (ไม่ได้กรองตัด category 'ขายของ' ออก) เพื่อให้ยอดขายของที่บันทึกจากตรงนี้ไปรวมแสดงในยอดรวมของ dashboard ด้วยอัตโนมัติ ถ้าพบว่ามีการกรองตัดออกอยู่ ให้แก้ให้รวมเข้าไปด้วย
