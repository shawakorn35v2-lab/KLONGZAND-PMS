เจอ 2 เรื่องต้องแก้ตามนี้:

**1. บั๊ก: บันทึก/แก้ไขการจองแบบ "พักค้างคืน" ไม่ได้ เจอ error "invalid input syntax for type time: ''"**

สาเหตุ: ตอนบันทึกฟอร์มการจอง (ทั้งสร้างใหม่และแก้ไข เช่นตอนโยกห้อง) ฟิลด์ checkin_time และ checkout_time ที่เพิ่งเพิ่มเข้ามาสำหรับฟีเจอร์ห้องชั่วคราว ถูกส่งเป็นค่าว่าง "" ไปที่ฐานข้อมูลเสมอ แม้ตอนเลือก "พักค้างคืน" ซึ่งไม่ควรมีค่าเวลาเลย ทำให้ Postgres ปฏิเสธ (column เป็นชนิด time รับค่าว่าง "" ไม่ได้ ต้องเป็น null)

แก้โดย: ในฟังก์ชันที่บันทึก/แก้ไขการจอง (create และ update) ให้ส่ง checkin_time และ checkout_time เป็น null ทุกครั้งที่ stay_type = 'overnight' หรือเมื่อผู้ใช้ไม่ได้กรอกค่า (ไม่ใช่ส่งเป็นสตริงว่าง "") ตรวจสอบทุกจุดที่มีการบันทึกการจอง (สร้างใหม่, แก้ไข, โยกห้อง) ให้ทำแบบเดียวกันให้หมด

**2. สิทธิ์: staff ต้องโยกห้อง (ย้ายห้องพัก) ได้ ไม่ใช่แค่ admin**

ตรวจสอบฟังก์ชัน/route ที่ใช้ทำ "โยกห้อง" (เปลี่ยนห้องของการจองที่มีอยู่) ว่าตอนนี้จำกัดไว้ให้ admin ทำได้เท่านั้นหรือไม่ ถ้าใช่ ให้ปลดล็อกให้ staff ทำได้ด้วย (เหมือนที่เคยปรับให้ staff บันทึกรายรับและข้อมูลห้องรายเดือนได้ก่อนหน้านี้)
