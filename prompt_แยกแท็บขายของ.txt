ที่หน้า /inventory ตอนนี้มีแท็บ สต๊อก / รับ-เบิก / คำขอ / ประวัติ ช่วยเพิ่มแท็บใหม่ชื่อ "ขายของ" แยกออกมาให้ชัดเจน ไม่ปนกับของใช้ภายในห้องพัก (ทิชชู่ สบู่ แชมพู ฯลฯ) ตามนี้:

**แท็บ "ขายของ" ใหม่ ให้มี:**

1. ปุ่ม "+ เพิ่มสินค้าขาย" — เปิดฟอร์มสร้างรายการของใหม่โดยตรง (ชื่อสินค้า, หน่วย, ราคาขาย/หน่วย) แล้วบันทึกเป็น inventory_items ที่มี is_for_sale = true ทันที โดยไม่ต้องไปสร้างที่แท็บสต๊อกทั่วไปก่อน

2. ตารางรายการสินค้าขาย — แสดงเฉพาะรายการที่ is_for_sale = true เท่านั้น (กรองออกจากของใช้ภายในห้องพักที่ is_for_sale = false หรือ null) แต่ละแถวมี: ชื่อสินค้า, สต๊อกคงเหลือ, ราคาขาย/หน่วย, ปุ่ม "รับเข้า" (เพิ่มสต๊อกตอนซื้อมา) และปุ่ม "ขาย" (บันทึกตอนขายได้)

3. ปุ่ม "รับเข้า" ในตารางนี้ → เปิดฟอร์มเล็ก กรอกจำนวนที่ซื้อมา + ราคาทุน/หน่วย (ไม่บังคับ) → บันทึกเป็น movement_type='stock_in' เพิ่มสต๊อกของรายการนั้น

4. ปุ่ม "ขาย" ในตารางนี้ → เปิดฟอร์มเล็ก กรอกจำนวนที่ขาย → ยืนยันแล้วบันทึก 2 อย่างพร้อมกัน (ถ้าอันใดพลาด ให้ทั้งคู่ไม่เกิด):
   - เพิ่มรายรับใน transactions: tx_type='income', category='ขายของ', amount = ราคาขาย x จำนวน, note = "ขาย <ชื่อสินค้า> x<จำนวน>"
   - บันทึก inventory_movements: movement_type='sale', quantity=จำนวน, transaction_id = id ของรายรับที่สร้างขึ้น
   - ถ้าจำนวนที่ขาย มากกว่าสต๊อกที่มี ให้เตือนและไม่บันทึก

5. แท็บ "สต๊อก" (รายการของเดิม) และ dropdown ในแท็บ "รับ-เบิก" เดิม ให้แสดงเฉพาะของใช้ภายในห้องพัก (is_for_sale = false หรือ null) เท่านั้น ไม่ต้องโชว์สินค้าขายซ้ำที่นั่นแล้ว เพื่อไม่ให้ปนกัน

6. แท็บ "ประวัติ" ให้คงการแสดงรวมทุกประเภท (รับเข้า/เบิกใช้ภายใน/ขาย) ไว้เหมือนเดิม แต่ทำ badge สีแยกประเภทให้ชัดเจน
