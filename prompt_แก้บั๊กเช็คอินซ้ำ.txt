ขอแก้ปัญหา: กดเช็คอินพลาดหลายครั้ง → สร้างรายการรายรับซ้ำ ให้แก้ 2 จุด

**จุดที่ 1 — app/actions/bookings.js ฟังก์ชัน checkinBooking()**

ก่อนที่จะ insert transaction ให้เช็คก่อนว่ามี transaction ของ booking นี้อยู่แล้วหรือยัง:

```javascript
// เช็คว่ามี transaction ค่าห้องของ booking นี้อยู่แล้วหรือยัง
const { data: existingTx } = await supabase
  .from('transactions')
  .select('id')
  .eq('booking_id', bookingId)
  .eq('category', 'ค่าห้อง')
  .limit(1)

if (remaining > 0 && (!existingTx || existingTx.length === 0)) {
  await supabase.from('transactions').insert({
    tx_date: getTodayString(),
    tx_type: 'income',
    category: 'ค่าห้อง',
    amount: remaining,
    note: roomNo ? `รับเงินเช็คอิน ห้อง ${roomNo} (ส่วนที่เหลือ)` : `รับเงินเช็คอิน (ส่วนที่เหลือ)`,
    booking_id: bookingId,
    created_by: user.id,
  })
}
```

(เพิ่มเงื่อนไข `&& (!existingTx || existingTx.length === 0)` ครอบ insert เดิม เพื่อกัน duplicate กรณีกดเช็คอินซ้ำ)

**จุดที่ 2 — app/(protected)/bookings/BookingsClient.js**

เพิ่ม confirmation dialog ก่อนเช็คอิน ในฟังก์ชัน handleAction (หรือที่ handle click ปุ่มเช็คอิน) ให้เพิ่ม confirm เฉพาะ action 'checkin':

```javascript
if (action === 'checkin') {
  const customerName = b.customers?.full_name ?? 'ลูกค้า'
  const roomNo = b.rooms?.room_no ?? ''
  const confirmed = window.confirm(
    `ยืนยันเช็คอิน ห้อง ${roomNo} — ${customerName}?\nรายการนี้จะสร้างรายรับในระบบ`
  )
  if (!confirmed) return
}
```

(เพิ่มก่อน await handleAction หรือก่อน call server action เช็คอิน)
