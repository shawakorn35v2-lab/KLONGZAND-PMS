ขอแก้ระบบบันทึกรายรับ ให้แยกเงินมัดจำกับค่าห้องส่วนที่เหลือ ตามวันที่รับเงินจริง

───────────────────────────
ปัญหาปัจจุบัน
───────────────────────────

- พนักงานสร้างการจอง ลูกค้าจ่ายมัดจำ 300 บาท → ระบบไม่บันทึกรายรับ
- พอถึงวันเช็คอิน กดเช็คอิน → ระบบบันทึกรายรับเต็ม 550 บาท ทีเดียว
- ผลคือ รายรับ 300 บาทที่รับจริงในวันจอง ไปโผล่ในวันเช็คอินแทน ยอดรายวันไม่ตรงความจริง

───────────────────────────
สิ่งที่ต้องการ
───────────────────────────

**1. ตอนสร้างการจอง (createBooking)**

ถ้ามีการกรอกเงินมัดจำ (deposit > 0):
→ insert transaction ทันที

```js
{
  tx_date: <วันที่สร้างการจอง วันนี้ ตาม Asia/Bangkok>,
  tx_type: 'income',
  category: 'ค่ามัดจำ',
  amount: depositAmount,
  booking_id: booking.id,
  note: `รับมัดจำ ห้อง ${roomName} (${customerName})`
}
```

**2. ตอนเช็คอิน (checkinBooking)**

เดิม insert รายรับเต็มจำนวนห้อง → เปลี่ยนเป็น insert เฉพาะ "ส่วนที่เหลือ"

```js
// ยอดมัดจำที่บันทึกไปแล้วสำหรับ booking นี้
const { data: paidDeposits } = await supabase
  .from('transactions')
  .select('amount')
  .eq('booking_id', booking.id)
  .eq('category', 'ค่ามัดจำ')

const depositPaid = (paidDeposits || []).reduce((s, r) => s + Number(r.amount), 0)
const remaining = Number(booking.total_amount) - depositPaid

// insert เฉพาะเมื่อยังมียอดค้าง
if (remaining > 0) {
  insert transaction {
    tx_date: checkInDate,   // ใช้วันเช็คอินจริง (แก้ไปแล้วก่อนหน้า)
    tx_type: 'income',
    category: 'ค่าห้อง',
    amount: remaining,
    booking_id: booking.id,
    note: `รับเงินเช็คอิน ห้อง ${roomName} (ส่วนที่เหลือ)`
  }
}
```

**สำคัญ:** ห้าม insert ซ้ำถ้ากดเช็คอินหลายครั้ง — เช็คก่อนว่ามี transaction category 'ค่าห้อง' ของ booking_id นี้อยู่แล้วหรือยัง ถ้ามีแล้วให้ข้าม

───────────────────────────
3. กรณี no-show / ยกเลิกการจอง
───────────────────────────

เงินมัดจำที่บันทึกไปแล้ว **ไม่ต้องลบหรือคืน** — ถือเป็นรายรับของรีสอร์ท
(ยึดมัดจำตามนโยบาย)

ตอนยกเลิกการจอง ให้ลบเฉพาะ transaction category 'ค่าห้อง' ที่ยังไม่ได้รับจริง (ถ้ามี)
แต่ transaction category 'ค่ามัดจำ' คงไว้เสมอ

───────────────────────────
4. UI ฟอร์มสร้างการจอง
───────────────────────────

ตรวจสอบว่าฟอร์มสร้างการจองมีช่องกรอก "เงินมัดจำ" อยู่แล้วหรือไม่
- ถ้ามี → ใช้ค่านั้นได้เลย
- ถ้าไม่มี → เพิ่มช่อง "เงินมัดจำ (บาท)" แบบ optional default 0

พร้อมข้อความช่วยเหลือใต้ช่อง:
"ใส่จำนวนเงินที่ลูกค้าจ่ายมาแล้ววันนี้ ถ้ายังไม่จ่ายให้ใส่ 0"

───────────────────────────
5. หน้ารายละเอียดการจอง
───────────────────────────

แสดงสรุปการชำระเงินให้พนักงานเห็นชัด:

```
ค่าห้องทั้งหมด    550 บาท
รับมัดจำแล้ว      300 บาท  (09/08/2569)
คงเหลือต้องเก็บ   250 บาท
```

ถ้าเช็คอินแล้วและเก็บครบ → แสดง "ชำระครบแล้ว" สีเขียว

───────────────────────────
ผลลัพธ์ที่ต้องการ
───────────────────────────

ตัวอย่าง: จองวันที่ 5 ส.ค. มัดจำ 300 / เข้าพัก 9 ส.ค. ค่าห้อง 550

- รายรับวันที่ 5 ส.ค. = 300 บาท (หมวด ค่ามัดจำ)
- รายรับวันที่ 9 ส.ค. = 250 บาท (หมวด ค่าห้อง)
- รวม 550 บาท ถูกต้อง ไม่ซ้ำซ้อน
