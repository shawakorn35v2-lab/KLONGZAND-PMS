ขอเพิ่ม visual indicator ในหน้ากริดห้องพัก (หน้าแดชบอร์ด/จองห้องพัก) เพื่อแสดงให้เห็นว่าห้องนั้นถูกจองกี่ครั้งในวันเดียวกัน โดยเฉพาะกรณีห้อง "ชั่วคราว" ที่ขายได้หลายรอบต่อวัน

**บริบท:**
- ปัจจุบันกริดห้องพักแสดงสีแดง = มีการจอง / สีเขียว = ว่าง
- ปัญหา: ถ้าห้อง A1 ถูกจองชั่วคราว 2 ครั้งในวันเดียวกัน ช่องนั้นแสดงสีแดงเหมือนกันทั้ง 1 ครั้งและ 2 ครั้ง พนักงานไม่รู้ว่าขายไปกี่รอบ

**ให้แก้ไขไฟล์ที่แสดงกริดห้องพัก (หาไฟล์เองจาก components หรือ app/(protected)/bookings/):**

**Logic ที่ต้องการ:**
1. สำหรับแต่ละช่อง (room × date) ให้นับจำนวน bookings ที่ overlap กับวันนั้น
2. ถ้า count = 1 → แสดงเหมือนเดิม (สีแดงปกติ)
3. ถ้า count = 2 → แสดง badge "×2" มุมขวาบนของช่อง + สีส้ม (เช่น bg-orange-500) แทนสีแดง
4. ถ้า count ≥ 3 → แสดง badge "×3" (หรือตามจำนวนจริง) + สีม่วง (เช่น bg-purple-600)

**ตัวอย่าง UI ของ badge:**
```jsx
{bookingCount > 1 && (
  <span className="absolute top-0 right-0 text-[10px] font-bold bg-white text-orange-600 rounded-bl px-1 leading-tight">
    ×{bookingCount}
  </span>
)}
```

**สีตามจำนวน:**
| จำนวนการจอง | สี | ความหมาย |
|---|---|---|
| 0 | เขียว (ว่าง) | ไม่มีการจอง |
| 1 | แดง (เดิม) | จองปกติ 1 ครั้ง |
| 2 | ส้ม + badge ×2 | ขายชั่วคราว 2 รอบ |
| 3+ | ม่วง + badge ×N | ขายชั่วคราวหลายรอบ |

**หมายเหตุ:**
- ช่อง (cell) ของกริดต้องมี position: relative เพื่อรองรับ badge absolute
- ต้องนับเฉพาะ bookings ที่ status ไม่ใช่ 'cancelled' (ถ้ามี field นั้น)
- ถ้ากริดแสดงแบบ week view หรือ day view ให้ใช้ logic เดียวกัน
