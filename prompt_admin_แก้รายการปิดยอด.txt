ที่หน้า /transactions (รายรับ-รายจ่าย) ตอนนี้รายการที่ "ปิดยอดแล้ว" (is_closed = true) จะแก้ไข/ลบไม่ได้เลยทั้ง admin และ staff ทำให้เวลายอดผิดต้องให้แก้ผ่าน SQL ตรงๆ ทุกครั้ง ช่วยปรับตามนี้:

1. ถ้าผู้ใช้ role = admin ให้สามารถกดแก้ไข/ลบรายการได้ แม้รายการนั้น is_closed = true แล้ว (ปลดล็อกเฉพาะ admin)

2. ถ้าผู้ใช้ role = staff ให้คงพฤติกรรมเดิมไว้ คือแก้ไข/ลบรายการที่ is_closed = true ไม่ได้ (ต้องให้ admin เป็นคนแก้)

3. ตอน admin กดแก้ไข/ลบรายการที่ is_closed = true ให้ขึ้น popup เตือนยืนยันก่อนเสมอ เช่น "รายการนี้ปิดยอดประจำวันไปแล้ว ยืนยันต้องการแก้ไข/ลบหรือไม่" กดยืนยันแล้วค่อยทำจริง เพื่อป้องกันแก้พลาด

4. ปุ่มแก้ไข/ลบ ที่เคยซ่อนไว้/ปิดไว้ (disabled) สำหรับรายการที่ปิดยอดแล้ว ให้แสดงให้ admin กดได้ตามปกติ (ส่วน staff ยังเห็นเป็นปุ่มที่กดไม่ได้เหมือนเดิม หรือซ่อนไปเลยก็ได้)

ทำเสร็จแล้ว build ทดสอบก่อน commit แล้วอัปเดต KLONGZAND_PMS_PROMPT.md ให้สะท้อนการแก้ไขนี้ด้วย
