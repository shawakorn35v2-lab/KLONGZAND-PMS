ต้องปรับ logic การกรองรายการในหน้า /inventory เพราะมีของบางอย่าง (เช่น "น้ำดื่ม") ต้องใช้ได้ 2 แบบพร้อมกัน คือ "เบิกใช้ในห้องพัก" (stock_out ปกติ) และ "เบิกมาขาย" (sale) โดยใช้สต๊อกก้อนเดียวกัน ไม่ใช่แยกเป็นของคนละชิ้น ช่วยแก้ตามนี้:

1. แท็บ "สต๊อก" (รายการของทั้งหมด) — ให้แสดงรายการของใช้ทุกชิ้น ไม่ว่า is_for_sale จะเป็น true หรือ false/null ก็ตาม (ยกเลิกการกรองตัด is_for_sale = true ออกจากรายการนี้ที่ทำไปก่อนหน้า) เพื่อให้เห็นสต๊อกของทุกอย่างรวมกันในที่เดียว ถ้าอยากแยกให้ดูง่าย อาจมี badge เล็กๆ ขึ้นว่า "ขายได้" ต่อท้ายชื่อของรายการที่ is_for_sale = true ก็ได้ (ไม่บังคับ)

2. dropdown เลือกสินค้าในแท็บ "รับ-เบิก" (ตอนกดเบิกของไปใช้ในห้องพัก) — ให้แสดงรายการของทุกชิ้นเหมือนเดิม ไม่ว่า is_for_sale จะเป็น true หรือ false ก็ตาม (ยกเลิกการกรองตัด is_for_sale = true ออกจาก dropdown นี้ที่ทำไปก่อนหน้า) เพราะของที่ขายได้บางชิ้นก็ต้องเบิกไปใช้ในห้องพักได้ด้วยเช่นกัน (เช่น น้ำดื่ม)

3. แท็บ "ขายของ" — ให้คงพฤติกรรมเดิมไว้ คือกรองแสดงเฉพาะรายการที่ is_for_sale = true เท่านั้น (ไม่เปลี่ยน)

4. สรุปคือ is_for_sale เป็นแค่ "แท็กบอกว่าของชิ้นนี้ขายให้ลูกค้าได้ด้วย" ไม่ได้แปลว่าของชิ้นนั้นห้ามเบิกไปใช้ในห้องพัก ของชิ้นเดียวกันใช้สต๊อกร่วมกันได้ทั้ง 2 ทาง (เบิกใช้ในห้อง ตัดสต๊อกแบบ stock_out / ขายให้ลูกค้า ตัดสต๊อกแบบ sale)
