ช่วยปรับหน้า /dashboard เพิ่มข้อมูลตามนี้ (กราฟยอดขายรายเดือน 12 เดือนที่มีอยู่แล้ว ให้คงไว้เหมือนเดิม ไม่ต้องแก้):

**1. สรุปข้อมูลรวมตั้งแต่อดีตถึงปัจจุบัน (ไม่จำกัดช่วงวันที่)**
เพิ่ม card แสดง:
- รายรับสะสมทั้งหมด (รวมทุกวันที่มีในระบบ)
- รายจ่ายสะสมทั้งหมด
- กำไรสุทธิสะสมทั้งหมด (รายรับ - รายจ่าย)
- จำนวนการจองทั้งหมดที่เคยมี (ทุกสถานะ ไม่จำกัดช่วงวันที่)

**2. Occupancy แบบเรียลไทม์ (ตอนนี้)**
เพิ่ม card แสดง "ห้องที่มีคนพักอยู่ตอนนี้ X / Y ห้อง (Z%)"
- Y = จำนวนห้องที่ is_active = true ทั้งหมด
- X = จำนวนห้องที่ถือว่า "มีคนพักอยู่วันนี้" คือห้องที่เข้าเงื่อนไขข้อใดข้อหนึ่ง:
  - มีการจอง (booking) ที่ checkin_date <= วันนี้ < checkout_date และสถานะไม่ใช่ cancelled หรือ
  - is_monthly = true และ monthly_start_date <= วันนี้ และ (monthly_end_date เป็น null หรือ monthly_end_date >= วันนี้)
- Z = (X/Y)*100 ทศนิยม 1 ตำแหน่ง

**3. Occupancy แบบรายเดือน (เลือกเดือนได้ default เป็นเดือนปัจจุบัน)**
เพิ่ม dropdown เลือกเดือน-ปี แล้วแสดง:
- "ห้อง-คืนทั้งหมดที่มี" = จำนวนห้อง active (Y) x จำนวนวันจริงในเดือนนั้น เช่น "19 ห้อง x 30 วัน = 570 ห้อง-คืน"
- "ห้อง-คืนที่มีคนพักจริง" = รวมจำนวนวันในเดือนนั้นที่แต่ละห้องเข้าเงื่อนไข "มีคนพัก" ตามสูตรข้อ 2 (นับทุกวันในเดือนนั้น ไม่ใช่แค่วันนี้) รวมห้องรายเดือนด้วย (นับทุกวันในช่วง monthly_start_date ถึง monthly_end_date ที่อยู่ในเดือนนั้น ถ้า monthly_end_date เป็น null ให้นับไปจนถึงวันสุดท้ายของเดือนนั้นหรือวันนี้ แล้วแต่ว่าอันไหนถึงก่อน)
- "อัตราเข้าพัก %" = (ห้อง-คืนที่มีคนพักจริง / ห้อง-คืนทั้งหมดที่มี) x 100 ทศนิยม 1 ตำแหน่ง

**4. กราฟ "อัตราเข้าพักแต่ละเดือน"**
กราฟแท่งหรือเส้น แสดง % อัตราเข้าพัก (ใช้สูตรข้อ 3) ของ 12 เดือนล่าสุด เรียงจากเดือนเก่าไปใหม่ แกน X เป็นชื่อเดือน (เช่น "พ.ค. 2569")
