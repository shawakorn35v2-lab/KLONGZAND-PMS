ตอนเพิ่มสินค้าขายในแท็บ "ขายของ" ที่ /inventory ถ้าผู้ใช้ตั้งชื่อสินค้าที่ซ้ำกับชื่อที่มีอยู่แล้วใน inventory_items (เช่น "น้ำดื่ม" ที่มีอยู่แล้วเป็นของใช้ภายในห้องพัก) ตอนนี้ระบบ insert ไม่ผ่านแล้วเด้ง error ดิบๆ ออกมาให้ผู้ใช้เห็น (duplicate key value violates unique constraint "inventory_items_name_key") ช่วยแก้ตามนี้:

1. ก่อน insert ให้เช็กก่อนว่ามีรายการชื่อนี้อยู่แล้วใน inventory_items หรือไม่ (query หาด้วยชื่อ ไม่สนตัวพิมพ์เล็ก-ใหญ่/เว้นวรรคหน้าหลัง)

2. ถ้ายังไม่มี → insert ตามปกติ (is_for_sale = true, sale_price = ตามที่กรอก)

3. ถ้ามีอยู่แล้ว และรายการเดิมนั้น is_for_sale ยังเป็น false/null → ไม่ต้อง error แต่ให้ขึ้น popup ถามผู้ใช้ว่า "มีสินค้าชื่อนี้อยู่แล้วในระบบ ต้องการตั้งให้ของเดิมนี้ขายได้เลยไหม" มีปุ่ม "ใช่ ตั้งเป็นสินค้าขาย" กับ "ยกเลิก"
   - ถ้ากด "ใช่" → update รายการเดิม set is_for_sale = true, sale_price = ตามที่กรอกในฟอร์ม (ไม่สร้างแถวใหม่ ใช้ของเดิมที่มีสต๊อกอยู่แล้ว)

4. ถ้ามีอยู่แล้ว และรายการเดิมนั้น is_for_sale = true อยู่แล้ว → แจ้งเตือนสั้นๆ ว่า "สินค้านี้เป็นสินค้าขายอยู่แล้ว" แล้วปิดฟอร์ม ไม่ insert ซ้ำ

ทำเสร็จแล้ว build ทดสอบก่อน commit แล้วอัปเดต KLONGZAND_PMS_PROMPT.md ให้สะท้อนการแก้ไขนี้ด้วย
